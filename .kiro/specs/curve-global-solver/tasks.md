# Implementation Plan

## Tasks

- [x] 1. 基盤モジュールとエラー型の拡張
- [x] 1.1 (P) キャリブレーションエラー型を拡張して新しいエラーケースを追加する
  - 空の商品リスト検出エラーを追加
  - 特異Jacobianエラーを条件数付きで追加
  - ソルバー発散エラーを反復数・残差付きで追加
  - 商品評価失敗エラーをインデックス・メッセージ付きで追加
  - _Requirements: 2.5, 9.1, 9.2, 9.4_

- [x] 1.2 (P) グローバルブートストラップ設定にJacobian計算方法とデバッグオプションを追加する
  - Jacobian計算方法の列挙型を定義（解析的、有限差分、将来のAAD）
  - 設定構造体にダンピング係数とデバッグログフラグを追加
  - Builder パターンによるメソッドチェーン設定を実装
  - デフォルト許容誤差 1e-10、最大反復数 100 を設定
  - _Requirements: 10.1, 10.2, 10.3, 10.5_

- [x] 1.3 (P) グローバルブートストラップ結果に診断情報を追加する
  - 反復ごとの残差履歴フィールドを追加（デバッグ用）
  - 最終Jacobian行列の条件数フィールドを追加
  - 収束状態と反復回数・最終残差を適切に格納
  - _Requirements: 9.3, 9.5_

- [x] 2. 時間グリッドと行列構築
- [x] 2.1 グローバル時間グリッドを実装してキャッシュフロー日付を管理する
  - キャリブレーション商品リストからすべてのキャッシュフロー日付を収集
  - 日付をソートし、重複を除去した統合グリッドを生成
  - 高速検索用のインデックスマップを構築（O(1) 検索）
  - 補間用の最近傍インデックス取得機能を実装
  - _Requirements: 8.1, 8.2_

- [x] 2.2 キャッシュフロー行列と補間行列を構築する
  - 商品ごとにグリッド上のキャッシュフロー係数を配置して行列 A を構築
  - 補間方法（LogLinear等）に基づいて補間行列 W を構築
  - 行列を定数としてキャッシュし、反復ごとの再計算を回避
  - 行列サイズの検証（商品数 × 日付数、日付数 × ピラー数）
  - _Requirements: 8.3, 8.4, 8.5_

- [x] 3. 商品評価器の実装
- [x] 3.1 (P) Deposit 評価器を実装してインプライドレートとJacobian行を計算する
  - 1 = (1 + r·δ)·DF(t_mat) の関係からインプライドレートを計算
  - 満期日の Discount Factor のみに依存する1要素のJacobian行を生成
  - Day Count Fraction を考慮したレート計算
  - _Requirements: 6.1, 6.2_

- [x] 3.2 (P) Futures/FRA 評価器を実装してフォワードレートとJacobian行を計算する
  - Forward Rate = (DF(t_start)/DF(t_end) - 1)/δ を計算
  - 開始日と終了日の2点に依存するJacobian行を生成
  - Convexity Adjustment の加算オプションを実装
  - _Requirements: 6.3, 6.4, 6.5_

- [x] 3.3 (P) テレスコープ法評価器を実装してOIS/SOFR商品を効率的に評価する
  - OIS変動脚を DF(t_start)/DF(t_end) - 1 として計算（日次ループ回避）
  - Payment Delay を考慮し、支払日の Discount Factor で割引
  - 2〜3個の非ゼロ要素を持つスパースなJacobian行を生成
  - Single Curve Framework 時の完全なテレスコープ簡約化を適用
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5_

- [x] 3.4 Swap 評価器を実装して固定脚・変動脚のPV差を計算する
  - 固定脚 PV と変動脚 PV の差をゼロにするパーレートを計算
  - 複数の支払日に対応するキャッシュフロー行列を構築
  - 各キャッシュフロー日付をグローバル時間グリッド上にマッピング
  - OIS スワップの場合はテレスコープ法を適用
  - _Requirements: 7.1, 7.2, 7.3, 7.4_

- [x] 4. Jacobian構築とカーブキャリブレーション問題
- [x] 4.1 Jacobian構築器を実装して解析的・数値的Jacobianを構築する
  - 有限差分法による数値Jacobianをデフォルト実装
  - 行列積 A·diag(-DF)·W による解析的Jacobianを実装
  - 補間行列 W を用いてピラーサイズに縮約
  - キャッシュフロー行列 A を定数として再利用
  - _Requirements: 3.1, 3.2, 3.4, 3.5_

- [x] 4.2 カーブキャリブレーション問題を連立方程式として定義する
  - パラメータ x = log(DF) でDiscount Factorを正に保つ
  - 残差関数 F(x) = 理論レート - 市場レート を計算
  - SystemOfEquations トレイトを実装して evaluate() と jacobian() を提供
  - 商品リストが空の場合はエラーを返す
  - 商品数とパラメータ数の一致を検証
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 2.6_

- [x] 5. グローバルソルバーの統合
- [x] 5.1 グローバルブートストラッパーに問題ベースのキャリブレーションを追加する
  - CurveCalibrationProblem を受け取る calibrate_with_problem() を実装
  - 既存の MultidimensionalNewtonSolver と連携
  - 収束判定（残差ノルム < 許容誤差）を実装
  - 最大反復到達時は ConvergenceFailure エラーを返す
  - Jacobian逆行列を結果に格納（AAD用）
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.6_

- [x] 5.2 発散検知とデバッグログ機能を実装する
  - 残差ノルム増大を検知して Divergence エラーを返す
  - Jacobian行列の特異性を条件数でチェック
  - デバッグモード時に各反復での残差ノルムをログ出力
  - _Requirements: 9.1, 9.2, 9.3_

- [x] 6. 統合テストと検証
- [x] 6.1 OISカーブ構築の統合テストを実装する
  - 5商品での標準的なOISカーブ構築を検証
  - すべての商品の pricing error < 1e-10 を確認
  - 収束反復数と残差ノルムを検証
  - 逆イールドカーブ（負の傾き）での安定性を確認
  - _Requirements: 1.1, 1.3, 5.1, 5.2_

- [x] 6.2 混合商品タイプでの収束を検証する
  - Deposit + Futures + Swap の組み合わせでのカーブ構築
  - 短期・中期・長期商品の混在シナリオ
  - 30ピラー規模でのパフォーマンス検証（< 100ms）
  - _Requirements: 6.1, 6.3, 7.1_

- [x] 6.3 解析Jacobianと数値Jacobianの一致を検証する
  - 解析 vs 数値Jacobianの相対誤差 < 1e-6 を確認
  - 各商品タイプでのJacobian行要素数を検証
  - Jacobian逆行列の J · J⁻¹ = I を検証
  - _Requirements: 3.1, 3.2, 3.4_

- [x] 7. AAD統合の準備
- [x] 7.1 ImplicitSolverとの連携を実装してカーブ感応度を計算する
  - Jacobian逆行列を ImplicitSolver に渡す
  - 陰関数定理 ∂x*/∂m = J⁻¹ による市場パラメータ感応度を計算
  - カーブ感応度（DV01、Key Rate Duration）を行列演算で計算
  - _Requirements: 4.1, 4.2, 4.3_
