## Tasks

- [x] 1. Feature Flagとコア型定義の追加
  - pricer_coreに`execution-trace` feature flagを追加し、トレース機能を条件付きコンパイル可能にする
  - ノードID、スコープID、演算タイプ、ソースコード位置を表す基本型を定義する
  - feature無効時にトレース関連コードがコンパイルから除外されることを検証する
  - _Requirements: 1.1, 7.1, 7.3, 7.4_

- [x] 2. 計算グラフ蓄積機能の実装
- [x] 2.1 ノードとエッジの蓄積構造を実装する
  - 計算グラフのノードとエッジを効率的に蓄積する構造を作成する
  - ノード追加時に演算タイプ、計算結果の値、入力ノードIDを記録する
  - ラベル付き入力ノード（MarketRate等の末端ノード）の作成機能を提供する
  - _Requirements: 1.3, 1.5, 1.6_

- [x] 2.2 スコープ階層管理機能を実装する
  - スコープの開始・終了を管理し、ネストしたスコープの親子関係を追跡する
  - スコープ内で生成されたノードを自動的にそのスコープに紐付ける
  - スコープ名の取得と保存機能を提供する
  - _Requirements: 3.3, 3.4, 3.6_

- [x] 2.3 計算グラフ蓄積機能の単体テストを作成する
  - ノード追加、エッジ生成、スコープ管理の正確性を検証する
  - ネストしたスコープでのノード紐付けをテストする
  - _Requirements: 1.3, 3.3, 3.4_

- [x] 3. トレース機能付き浮動小数点型の実装
- [x] 3.1 トレース機能付き浮動小数点型の基本構造を実装する
  - f64値をラップし、計算グラフへの参照を保持する型を作成する
  - ラベル付き入力値の作成機能を提供する
  - 値とノードIDの取得メソッドを実装する
  - _Requirements: 1.1, 1.6, 2.1_

- [x] 3.2 全Float演算のトレース対応を実装する
  - num_traits::Float traitの全メソッド（約75個）を実装する
  - 各演算メソッドでソースコード位置を自動取得する
  - 演算結果を計算グラフに自動登録する
  - _Requirements: 1.2, 1.4, 2.1, 2.2_

- [x] 3.3 (P) 算術演算子のトレース対応を実装する
  - Add, Sub, Mul, Div演算子を実装し、計算グラフノードを自動生成する
  - Neg, Rem等の追加演算子も対応する
  - 各演算でソースコード位置を記録する
  - _Requirements: 1.2, 2.1, 2.2_

- [x] 3.4 トレース機能付き浮動小数点型の単体テストを作成する
  - 全Float演算がf64と同じ結果を返すことを検証する
  - 計算グラフが正しく構築されることを検証する
  - ソースコード位置が正しく記録されることを検証する
  - _Requirements: 1.2, 1.3, 1.4, 2.2_

- [ ] 4. 自動スコープ生成マクロの実装
- [ ] 4.1 (P) マクロ用クレートを新規作成する
  - proc-macro用のクレートを作成し、ワークスペースに追加する
  - syn, quote依存関係を設定する
  - pricer_coreからの参照を設定する
  - _Requirements: 3.1_

- [ ] 4.2 関数境界でスコープを自動生成する属性マクロを実装する
  - 関数本体をスコープ開始・終了でラップするマクロを作成する
  - 関数名をデフォルトスコープ名として使用する
  - カスタムスコープ名の指定機能を提供する（name属性）
  - _Requirements: 3.1, 3.2, 3.5_

- [ ] 4.3 マクロのfeature flag連携を実装する
  - execution-trace feature無効時にマクロがno-op展開となるよう実装する
  - 通常ビルドでゼロオーバーヘッドを保証する
  - _Requirements: 3.8_

- [ ] 4.4 自動スコープ生成マクロの単体テストを作成する
  - マクロ展開の正確性を検証する
  - feature flag有効/無効時の動作を検証する
  - ネストした関数呼び出しでのスコープ階層を検証する
  - _Requirements: 3.1, 3.2, 3.8_

- [x] 5. グラフエクスポート機能の実装
- [x] 5.1 (P) 詳細度レベルに応じたグラフ変換機能を実装する
  - 計算グラフ蓄積構造から表示用グラフ形式への変換機能を作成する
  - Operation（四則演算）レベルでの全ノード出力を実装する
  - 既存のグラフ型との互換性を維持する
  - _Requirements: 4.1, 4.3, 7.5_

- [x] 5.2 (P) スコープ集約機能を実装する
  - Scope（スコープ）レベルでスコープを1ノードに集約する機能を実装する
  - スコープ間のエッジのみを抽出・表示する
  - クライアント側で詳細度切り替えが可能なよう全情報を含める
  - _Requirements: 4.2, 4.4_

- [x] 5.3 グラフエクスポート機能の単体テストを作成する
  - Operationレベル、Scopeレベル両方の変換を検証する
  - スコープ集約ロジックの正確性を検証する
  - _Requirements: 4.1, 4.2_

- [x] 6. REST APIエンドポイントの実装
- [x] 6.1 APIリクエスト・レスポンス型を定義する
  - 計算パラメータと詳細度レベルを受け取るリクエスト型を定義する
  - D3.js互換のノード・エッジ・スコープ配列を返すレスポンス型を定義する
  - ソースコード位置とスコープID情報を含める
  - _Requirements: 6.3_

- [x] 6.2 計算グラフ取得エンドポイントを実装する
  - /api/pricer/graphエンドポイントを追加する
  - リクエストパラメータでの計算実行とグラフ生成を実装する
  - エラー発生時に詳細情報を含むレスポンスを返却する
  - _Requirements: 6.1, 6.2, 6.4_

- [x] 6.3 REST APIの統合テストを作成する
  - エンドポイントの正常系・異常系を検証する
  - レスポンス形式がD3.js互換であることを検証する
  - _Requirements: 6.1, 6.3_

- [x] 7. WebApp UIの改修
- [x] 7.1 (P) ページ名を「Instrument Graph」から「Pricer Graph」に改名する
  - ナビゲーション、ページタイトル、内部参照を更新する
  - URLパスの変更（必要に応じてリダイレクト設定）
  - _Requirements: 5.1_

- [x] 7.2 (P) ノードクリック時の詳細情報表示を実装する
  - 演算タイプ（Add, Mul, Sqrt等）を表示する
  - 入力値と出力値を表示する
  - ソースコード位置（ファイル名:行番号:列番号）を表示する
  - 所属スコープを表示する
  - _Requirements: 5.3, 2.5_

- [x] 7.3 (P) スコープの視覚化を実装する
  - スコープを破線枠または背景色で視覚的に区別する
  - スコープの境界を明確に表示する
  - _Requirements: 5.4_

- [ ] 7.4 スコープの展開・折り畳み機能を実装する
  - スコープダブルクリックで展開・折り畳みを切り替える
  - 折り畳み状態でスコープを1ノードとして表示する
  - _Requirements: 5.5, 3.7_

- [x] 7.5 詳細度切り替えトグルを実装する
  - Operation / Scopeレベルの切り替えUIを追加する
  - トグル切り替え時にグラフ表示を更新する
  - _Requirements: 4.5, 5.7_

- [x] 7.6 グラフ操作機能を実装する
  - ズーム、パン機能を提供する
  - ノード検索機能を追加する
  - _Requirements: 5.6_

- [ ] 8. 統合テストとパフォーマンス検証
- [ ] 8.1 既存価格計算関数との統合テストを作成する
  - 既存のT: Floatジェネリック関数にトレース機能付き型を渡してグラフ取得を検証する
  - 複数の価格計算シナリオでグラフの正確性を検証する
  - 既存コードに変更が不要であることを確認する
  - _Requirements: 1.4, 7.2, 7.6_

- [ ] 8.2 エンドツーエンドテストを作成する
  - WebApp UIからAPI経由でグラフ表示までの一連のフローを検証する
  - 詳細度切り替え、スコープ展開・折り畳みの動作を検証する
  - _Requirements: 5.2, 5.5_

- [ ]*  8.3 パフォーマンステストを実施する
  - 10,000ノードのグラフ生成が目標時間内に完了することを検証する
  - 通常f64計算に対するオーバーヘッドが許容範囲内であることを確認する
  - トレース機能無効時にパフォーマンス影響がないことを検証する
  - _Requirements: 7.6_
