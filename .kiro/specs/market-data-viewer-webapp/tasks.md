# Implementation Plan

## Overview

本タスクリストは、Market Data Viewer WebApp 機能の実装タスクを定義する。バックエンド（DTO 型定義、サンプルデータ生成、REST API ハンドラー）からフロントエンド（UI セクション、エクスポート機能）への段階的な実装を行う。

---

## Tasks

- [x] 1. Web API DTO 型定義
- [x] 1.1 (P) マーケットレートレスポンス型を定義する
  - API レスポンス用の DTO 構造体を作成し、serde による camelCase シリアライズを設定する
  - レート一覧レスポンス（レート配列、最終更新タイムスタンプ、総件数）を定義する
  - クエリパラメータ型（通貨、レートタイプ、インデックスのオプショナルフィルタ）を定義する
  - _Requirements: 1.1, 1.3, 1.4, 5.1, 5.2_

- [x] 1.2 (P) Instrument/Convention レスポンス型を定義する
  - Instrument 情報を表現する DTO（商品タイプ、通貨、開始日、終了日、レート、パラメータ）を定義する
  - Convention 情報を表現する DTO（コンベンションタイプ、フィールドラベル/値ペア配列）を定義する
  - 詳細レスポンス型（レート情報 + Instrument + Convention の複合）を定義する
  - Convention 一覧およびサマリ型を定義する
  - _Requirements: 2.1, 2.2, 3.1, 3.2, 5.3, 5.4, 5.5, 5.6_

- [x] 1.3 (P) API エラーレスポンス型を定義する
  - 構造化されたエラーレスポンス（エラーコード、メッセージ、詳細）を定義する
  - 404 Not Found および 400 Bad Request のエラーケースに対応する
  - _Requirements: 5.7_

- [x] 2. サンプルマーケットデータ生成
- [x] 2.1 USD マーケットレートデータを生成する
  - SOFR OIS レート（ON, 1W, 1M, 3M, 6M, 1Y）のサンプルデータを作成する
  - USD Swap レート（2Y, 3Y, 5Y, 7Y, 10Y, 15Y, 20Y, 30Y）のサンプルデータを作成する
  - 各レートに適切なタイムスタンプ、クォートタイプ（Mid）、ソース情報を設定する
  - _Requirements: 1.1, 1.2_

- [x] 2.2 EUR マーケットレートデータを生成する
  - EURIBOR Deposit レート（1M, 3M, 6M, 1Y）のサンプルデータを作成する
  - EUR Swap レート（2Y, 3Y, 5Y, 7Y, 10Y, 15Y, 20Y, 30Y）のサンプルデータを作成する
  - _Requirements: 1.1, 1.2_

- [x] 2.3 JPY マーケットレートデータを生成する
  - TONAR OIS レート（ON, 1W, 1M, 3M, 6M, 1Y）のサンプルデータを作成する
  - JPY Swap レート（2Y, 3Y, 5Y, 7Y, 10Y, 15Y, 20Y, 30Y）のサンプルデータを作成する
  - _Requirements: 1.1, 1.2_

- [x] 2.4 (P) FX スポットレートデータを生成する
  - USDJPY および EURUSD のスポットレートを作成する
  - FX レートタイプとして適切に分類する
  - _Requirements: 1.1, 1.2_

- [x] 2.5 Convention プリセットデータを生成する
  - USD SOFR スワップ、EUR EURIBOR 6M スワップ、JPY TONAR スワップのコンベンションセットを用意する
  - EUR/USD、USD/JPY の FX コンベンションを用意する
  - 各通貨のデフォルトコンベンションを指定する
  - _Requirements: 3.3, 3.5_

- [x] 3. REST API ハンドラー実装
- [x] 3.1 AppState にマーケットデータキャッシュを追加する
  - マーケットレートセットを保持するキャッシュフィールドを追加する
  - コンベンションセットを保持するキャッシュフィールドを追加する
  - 最終更新タイムスタンプを保持するフィールドを追加する
  - 遅延初期化（初回アクセス時にサンプルデータ生成）のロジックを実装する
  - _Requirements: 1.2, 6.1_

- [x] 3.2 レート一覧取得エンドポイントを実装する
  - GET /api/market/rates エンドポイントを作成する
  - 通貨、レートタイプ、インデックスによるフィルタリング機能を実装する
  - キャッシュからデータを取得し、DTO に変換してレスポンスを返す
  - _Requirements: 5.1, 5.2_

- [x] 3.3 レート詳細取得エンドポイントを実装する
  - GET /api/market/rates/{rate_id} エンドポイントを作成する
  - rate_id からレートを検索し、Instrument マッピングを実行する
  - Convention 情報を取得して詳細レスポンスを構築する
  - レートが見つからない場合は 404 エラーを返す
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 3.1, 3.2, 5.3, 5.4_

- [x] 3.4 (P) Convention エンドポイントを実装する
  - GET /api/market/conventions エンドポイント（一覧）を作成する
  - GET /api/market/conventions/{convention_id} エンドポイント（詳細）を作成する
  - Convention フィールドをユーザーフレンドリーなラベル形式に変換する
  - _Requirements: 3.1, 3.4, 5.5, 5.6, 5.7_

- [x] 3.5 ルーターにマーケットデータエンドポイントを登録する
  - 7 つの新規エンドポイントを Axum ルーターに追加する
  - 既存のルーティング構造と整合性を保つ
  - _Requirements: 5.1, 5.3, 5.5, 5.6_

- [x] 4. フロントエンド Market Data セクション
- [x] 4.1 Market Data セクションの HTML 構造を作成する
  - 既存の index.html に Market Data タブ/セクションを追加する
  - ヘッダー（タイトル、最終更新時刻、リフレッシュボタン）を配置する
  - フィルター領域（通貨タブ、タイプマルチセレクト、検索ボックス）を配置する
  - レートテーブルのコンテナを配置する
  - 詳細パネル（モーダルまたはサイドパネル）の枠組みを配置する
  - _Requirements: 4.1, 4.2_

- [x] 4.2 Market Data セクションのスタイルを適用する
  - 既存の Glass morphism デザインパターンに合わせたスタイルを適用する
  - テーブルのソート可能ヘッダー、ホバー効果、クリック可能な行のスタイルを設定する
  - レスポンシブレイアウト（デスクトップ・タブレット対応）を設定する
  - _Requirements: 4.5, NFR 2.1, NFR 2.2_

- [x] 4.3 マーケットデータ取得・表示ロジックを実装する
  - API からレートデータを取得する JavaScript 関数を実装する
  - 取得したデータをテーブルに描画する機能を実装する
  - ローディングインジケータの表示/非表示を制御する
  - Stale レートの視覚的インジケータ（警告アイコン、グレーアウト）を表示する
  - _Requirements: 1.4, 1.5, 4.6_

- [x] 4.4 フィルタリング・ソート機能を実装する
  - 通貨タブによるフィルタリングを実装する
  - レートタイプによるマルチセレクトフィルタを実装する
  - 検索ボックスによる rate_id/tenor 検索を実装する
  - テーブルカラムヘッダークリックによるソートを実装する
  - _Requirements: 4.2, 4.3_

- [x] 4.5 レート詳細パネルを実装する
  - テーブル行クリック時に詳細 API を呼び出す
  - レートメタデータ、Instrument 詳細、Convention テーブルを表示するパネルを描画する
  - Instrument マッピング失敗時のエラー表示を実装する
  - _Requirements: 2.2, 2.4, 3.2, 4.4_

- [x] 5. データ更新とリフレッシュ機能
- [x] 5.1 リフレッシュ機能を実装する
  - リフレッシュボタンクリック時に API を再呼び出しする
  - リフレッシュ中のローディングスピナーを表示する
  - リフレッシュ失敗時のエラーメッセージとリトライオプションを表示する
  - _Requirements: 6.2, 6.3, 6.4, 6.5_

- [x] 5.2 レート変更ハイライト機能を実装する
  - 前回のデータと比較してレート値の変化を検出する
  - 上昇/下降を示す色付きインジケータを表示する
  - _Requirements: 6.6_

- [x] 6. データエクスポート機能
- [x] 6.1 CSV エクスポート機能を実装する
  - エクスポートボタンを UI に追加する
  - 現在のフィルタ設定を反映したデータを CSV 形式で生成する
  - ヘッダー行（Rate ID, Currency, Tenor, Type, Value, Quote Type, Timestamp, Source）を含める
  - ファイルダウンロードをトリガーする
  - _Requirements: 7.1, 7.2, 7.4, 7.5_

- [x] 6.2 (P) JSON エクスポート機能を実装する
  - JSON エクスポートボタンを UI に追加する
  - メタデータセクション（エクスポート日時、フィルタ条件）と rates 配列を含む JSON を生成する
  - Instrument および Convention 情報を含めたフルエクスポートを実装する
  - _Requirements: 2.5, 7.1, 7.3, 7.4, 7.5_

- [x] 7. 統合テストと検証
- [x] 7.1 API エンドポイントの統合テストを作成する
  - GET /api/market/rates のフィルタリング動作を検証する
  - GET /api/market/rates/{rate_id} の正常系・異常系を検証する
  - Convention エンドポイントの動作を検証する
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5, 5.6, 5.7_

- [x] 7.2 DTO シリアライズのユニットテストを作成する
  - MarketRateResponse の JSON シリアライズ/デシリアライズを検証する
  - camelCase 変換が正しく機能することを検証する
  - _Requirements: 1.4_

- [ ]* 7.3 フロントエンド機能の手動検証を実施する
  - 通貨タブ切り替えとフィルタリングの動作を確認する
  - レート行クリックによる詳細パネル表示を確認する
  - CSV/JSON エクスポートのダウンロードを確認する
  - _Requirements: 4.1, 4.2, 4.3, 4.4, 7.1, 7.2, 7.3_
